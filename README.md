# GreenTrack Web System

A web-based community recycling tracking and ranking system developed as a Final Year Project.

## 🚀 Features
- User registration and login
- Recycling data tracking
- Leaderboard ranking system
- Certificate generation with QR code
- Admin dashboard

## 🛠 Technologies Used
- Python (Flask)
- HTML, CSS, JavaScript
- SQLite Database

## 📦 How to Run
1. Install Python
2. Install Flask
3. Run:
   python app.py
4. Open browser:
   http://localhost:5000

## 📌 Note
Database and generated files are excluded using .gitignore.
